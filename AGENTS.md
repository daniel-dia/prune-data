# AGENTS.md

- Keep runtime dependencies at zero and the package ESM-only.
- Keep the single public function in `src/index.ts`.
- Do not edit `dist/`; it is generated by `npm run build`.
- Add a `node:test` case for every behavior change.
- Require Node.js 24 or newer. Tests import `src/index.ts` directly through Node's native TypeScript support; they do not use `dist/`.
- Keep `npm run build` on `tsgo`, supplied by `@typescript/native-preview`. Do not switch it to `tsc`.
- Keep `typescript@5.9` as a development-only dependency for Stryker's `tsconfig.json` preprocessing; it is not used by the build.
- Run `npm test`, `npm run coverage`, and `npm run mutation` before publishing.
- Preserve the public behavior: recursively clean only plain objects and arrays without mutating input, and preserve non-plain objects such as `Date`, `Map`, and class instances.
